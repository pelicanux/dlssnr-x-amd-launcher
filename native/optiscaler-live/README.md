# Experimental OptiScaler NR launcher control

Adaptation by Pelicano / pelicanux for the DLSSNR X AMD launcher.
Original OptiScaler and Neural Rendering work remains credited to its authors.
This adaptation is **GPLv3**, like the upstream OptiScaler fork. It is not part
of the launcher's MIT license grant.

## Pinned source

- Repository: https://github.com/wilsjo2/OptiScaler-DLSSNR-PreSR-Multipass
- Version: v0.8.4, used by the Mochizuki Linux backend.
- Commit: 8802b2b470db0462fa1ed03a125e793a7c06d735.
- Original notices and the upstream LICENSE must remain intact.

`patch-optiscaler-live.py` verifies the original menu file's SHA-256 before
modifying it. It adds `LauncherControl.h` and polls the receiver from both
`MenuCommon::Present` and `UpdateRenderTiming`, including overlay rendering.

A command updates `Config::Instance()->DlssNrEnabled`, the same state used by
“Enable Neural Rendering” and the existing NR shortcut. It does not unload the
mod, change ApplyModel, change the upscaler, or change other settings. Commands
are applied once so later manual changes inside the game remain authoritative.

The DLL exports `DLSSNR_LauncherControlProtocolV1` so the launcher can distinguish
this adapted version from an official DLL. The communication protocol matches
the ReShade bridge: UUID + LF + 0/1 + LF, exactly 39 bytes, via files next to
the installed DLL. An acknowledgement is written only after updating and
verifying the live configuration. No game-memory inspection or keyboard
simulation is involved.

## Build and source distribution

The full DLL uses Visual Studio 2022/MSBuild with Windows SDK and the upstream
submodules. On Windows:

1. Clone the pinned upstream commit with recursive submodules.
2. Run `python scripts/patch-optiscaler-live.py <upstream-folder>` from the launcher.
3. Inside upstream, run `msbuild OptiScaler.sln /m /p:Configuration=Release /p:Platform=x64`.

`.github/workflows/build-optiscaler-live.yml` performs this build on Windows 2022
and packages the generated DLL with the full patched source, submodules, license,
metadata and build workflow. It creates a build artifact; it does not publish
a release or replace the launcher's normal backend downloads.

When distributing this modified DLL, also distribute its corresponding source
and license as generated by that workflow. Keep the upstream dependency notices;
this adaptation does not grant rights to redistribute NVIDIA model files.

## Verification and status

The receiver's standalone test checks live toggling, exact acknowledgement,
preservation of later manual checkbox changes, invalid packets and failures.
Compile/run it on Linux with:

```sh
g++ -std=c++17 -Wall -Wextra -Werror native/optiscaler-live/receiver-test.cpp -o /tmp/opti-receiver-test
/tmp/opti-receiver-test
```

The full modified DLL has **not yet been built or validated in a real game**.
The launcher keeps normal startup-only behavior with an unmodified DLL. Once
a modified DLL is installed, restart the game once and then test the switch
with the game running. In-game effect verification remains necessary.
